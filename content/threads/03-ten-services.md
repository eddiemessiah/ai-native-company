# Thread 3: 10 AI-native services I'd start in Lagos this month

1/
10 AI-native services I'd start in Lagos this month.

Each one: work businesses already pay people to do, a checkable right answer, and a unit you can price per job.

Bookmark this 🧵

2/
1. "What AI says about you" audits

Ask ChatGPT, Claude and Gemini 25 questions a buyer would ask about a business. Screenshot what's wrong. Sell the fix.

Unit: per audit, ₦60k. First one free. You're selling the screenshot.

3/
2. WhatsApp order lines for restaurants and farms

An assistant that answers price and delivery questions and sends a payment link. Complaints go to a person.

Unit: setup + monthly. ₦300k + ₦35k/mo, against a ₦150–250k/month receptionist.

4/
3. Grant & RFP desk

Score the draft against the funder's rubric, rewrite the 3 weakest sections with evidence, and date the milestones.

Unit: per application, $350. Grant writers charge $1–5k.

5/
4. AML alert triage for fintechs

The CBN's automated-AML standards have an 18–24 month window. Score alerts, close false positives with evidence, and draft STRs. An analyst approves every filing.

Unit: per alert, ~$0.40 vs ~$1 of analyst time.

6/
5. Agent reliability audits

Before an agent touches money or customers: consistency, robustness, calibration, data leaks. Reproducible traces for the examiner.

Unit: per workflow, from $3k. Princeton's agent team pivoted to exactly this.

7/
6. Company brains for startups

An AI teammate in Slack that remembers decisions and knows when to stay quiet. Open-source harness + a typed decision layer for triage.

Unit: setup + monthly care.

8/
7. Weekly creative packs

Posts, reel scripts and catalog updates for fashion, food and agro brands, in the brand's own voice, approved by the owner every Monday.

Unit: ₦60k/month vs a ₦150–300k social manager.

9/
8. KYC file pre-checks

Missing documents, mismatched names and expired IDs flagged before a compliance officer opens the file. Code compares names and dates; the model never approves anyone.

Unit: per file.

10/
9. AfCFTA trade desk

HS-code classification and document checks for exporters. Code narrows the tariff candidates, the model picks between finalists, a licensed broker signs off.

Unit: per shipment.

11/
10. An agent spend firewall

For agents that pay with x402: budgets and allowlists in code, a "does this match what the user asked?" check, and human approval above the limit. Receipts for every payment.

Unit: per agent wallet per month.

12/
The pattern in all 10:

The model answers typed questions.
Code does the exact parts.
A person owns anything irreversible.

That's a service business that runs like software.
