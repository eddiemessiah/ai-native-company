# Thread 7: GTM Harness launch (Tue 29 Sep)

Post it with a 60-second screen recording of a real run, and pin it for launch week. Before posting, check "about a minute" against your own timed run (`company/gtm/gtm-harness-launch.md`).

21 files.

That's what a founder gets from GTM Harness in about a minute: a go-to-market plan, three reviewed first messages, and a folder their own agents keep running in Claude Code.

It's free and open source (MIT). Here's what's inside 🧵

2/
You fill in one form: the product, who it's for, your goal for the month, and the channels you can use.

You get:

• an ideal-customer scorecard with weights (80%+ reach out, 60–80% nurture, under 60% skip)
• where those customers already gather
• a 7-day sprint
• a Monday dashboard of five numbers

3/
You also get three first messages, each checked by a reviewer before you see it.

The reviewer can block a draft but never send one. It blocks invented numbers and pushy asks. It marks the rest ready or revise, with the fixes.

You send everything yourself.

4/
Then download the harness, a folder for Claude Code:

• CLAUDE.md, the operating manual
• your scorecard, sources and pipeline.csv
• rules for voice, outreach and claims
• one prompt per role: sourcer, scorer, preparer, reviewer, follow-up, weekly review

5/
The file that matters most is corrections-log.md.

Every time you fix a draft, write down what was wrong. A correction that comes up twice becomes a rule.

A month in, your agents write the way you would, because you taught them.

6/
Every run uses the same split:

• an LLM writes the plan and the drafts
• a decision model reviews them
• code does the math and packs the folder
• a person sends

The code is MIT-licensed: github.com/eddiemessiah/ai-native-company/tree/main/packages/gtm-harness

7/
